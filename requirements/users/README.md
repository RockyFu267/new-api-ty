# 用户部门管理

## 2026-10-13：平级部门与用户归属

- 管理员自行创建、重命名和删除平级部门，不支持上下级部门。
- 每个用户同一时间最多归属一个部门，也可以不属于任何部门。
- 用户管理页提供“部门管理”入口；列表显示部门，并允许管理员逐人分配、更换或清空。
- 筛选区增加非必选的部门条件：未选时查询所有用户；可选择指定部门或“未分配”。筛选在服务端执行并正确计算分页总数。
- 本地和 AD 用户共用部门能力，部门归属由管理员维护，AD 同步不覆盖人工分配。
- 部门不影响现有模型分组、权限和计费。修改用户部门沿用现有用户管理的角色边界。
- 删除部门前展示部门名称及用户数量并要求确认；删除后用户变为“未分配”，保留账号。
- 部门及归属独立保存到数据库，迁移数据库时一起迁移；新增用户默认未分配。
- 本阶段不提供多级部门、多部门归属、AD 部门自动同步或部门权限配置。
