# TIANYAN Demo 需求管理

本目录用于持续记录 TIANYAN 内部 Demo 的需求、范围、验收状态和技术评估。

## 永久约束

- 任何需求的新增、删除、修改、范围调整和验收结论，都必须在代码变更的同一批次同步更新本目录中的对应文档。
- 需求文档是后续实现和验收的依据；代码与文档不一致时，必须先补齐文档并明确差异。
- 隐藏功能默认只移除 UI 入口，保留路由、接口、源码和数据；只有需求明确要求删除时才执行清理。
