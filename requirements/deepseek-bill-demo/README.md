# DeepSeek Flash 原厂峰谷计费与历史模拟账单

确认时间：2026-11-09。

## 范围

- 个人菜单提供“DeepSeek 计费”，兼容路径 `/deepseek-bill-demo`，所有登录用户可访问。管理员可管理规则版本并查看全员汇总、人员筛选及明细；普通用户只能查看自己的日期范围汇总和逐次明细，不显示用户列表、人员选择器或规则表单。
- `GET /api/user/deepseek-bill-demo` 普通用户强制采用登录身份，在数据库查询阶段限定本人记录，忽略传入的 `user_id`；总额、用户列表、明细和分页数量均不得包含其他用户的数据。管理员按原逻辑可查全员。
- 只读消费日志，模型名精确匹配 `deepseek-v4.1-flash`；默认最近 30 个北京时间自然日。只有期间存在该模型消费记录的用户才显示，保留历史用户名及用户 ID。
- 按用户汇总请求数、输入、缓存命中、输出、高峰费用、低峰费用、模拟总费用及估算记录数；点击用户或下拉选择查看逐次明细，每页 50 条。
- 输入包含缓存命中，费用按“未命中输入＋缓存命中输入＋输出”计算，不重复计算缓存。Token 以 M、费用以人民币展示，不进行美元汇率换算。
- 不新增独立配额池。启用后的 DS 新请求按专用原厂规则计算额度，沿用现有部门日/周/月共同上限、配额不足时钱包兜底、钱包不足拒绝新请求。钱包、API Key、用量统计、费用账本继续沿用统一结算；其他模型不受影响。
- 单次长任务可以结算后略超额度，但下次请求受原有配额检查约束。历史记录只回算展示，不追扣、不重写旧日志或旧配额。

## 专用规则管理（2026-11-10 本地版）

- 管理员 `GET/PUT /api/user/deepseek-billing/rules` 管理不可变版本：启用状态、六项峰谷单价（人民币／百万 Token）、工作日高峰时段、低峰假期日期、人民币兑美元记账汇率、生效时间。普通用户访问管理接口返回 403。
- 版本写入已有 options 表的 `DeepSeekBillingRules`，不新增数据库表。发布采用事务与修订号校验，拒绝并发旧版本覆盖或追溯生效；通用 option 编辑接口不得绕过专用入口修改历史版本。版本保留发布人，计费日志保留请求采用的完整规则、版本和汇率。
- 默认草稿为原厂参考价，高峰 2/0.04/8、低峰 1/0.02/4；汇率 7.3 只是明确可修改的本地测试初始记账值，并非自动获取的市场汇率。新环境默认未启用，未启用时保留普通模型定价。
- 请求开始时锁定有效版本及峰谷归属；重试、跨时段完成、管理员修改规则均不改变该请求。预扣与实际结算使用同一快照，实际结算用已规范化的 Token，缓存不重复计算。
- 启用时覆盖 `deepseek-v4.1-flash` 的普通价格、表达式及分组倍率，按原厂价收取，不叠加折扣或加价。模型定价页对已启用专用计费的模型提供提示和跳转。
- 历史模拟费用与实际专用计费分别标记；实际记录展示保存的单价、版本、汇率和实际扣额（美元）。合计明确标注为“实际计费＋历史模拟”，不会将历史模拟额冒充实际配额消耗。

## 计价口径与准确性边界

- 当前规则快照取自 2026-11-09 的[DeepSeek 官方价格页](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)。低峰每百万 Token：未命中输入 1 元、缓存命中 0.02 元、输出 4 元；高峰分别为 2、0.04、8 元。
- 高峰为北京时间周一至周五 09:00（含）至 12:00（不含）、14:00（含）至 18:00（不含）；周末及节假日假期低峰。当前 Demo 的 2026 年假期依据[国务院办公厅 2026 年放假通知](https://www.gov.cn/zhengce/zhengceku/202511/content_7047091.htm)，覆盖本计价政策之后的中秋节及国庆节假期；调休周末仍按周末低峰处理。
- **这是用当前原厂价格回算历史用量的模拟结果，不是已核实的历史价格账单或优刻得实际账单。** 未验证的旧价格版本不冒充历史实付；供应商收单时刻、舍入和折扣还需供应商对账。
- 消费日志时间是结束时间，优先从网关 request_id 的 UTC 时间前缀恢复开始时间（仅接受结束前 24 小时内的有效时间）。无法恢复时使用日志时间，标为估算。跨午夜的请求通过额外一天候选日志读取后按开始时间过滤。
- 沿用现有 Token 规范化逻辑；缺少可靠用量来源、缓存上报或请求开始时刻的记录标为估算。缺少缓存上报时按未命中价格估算。损坏 JSON、异常 Token 数或命中数超过输入的记录标为未计价，其费用不进入总费用。
- 使用整数 1e-8 元累加，最后展示到小数点后 6 位；不对每次请求先四舍五入到分。
- 日期支持 2026-08-17 至查询当天，单次最多 90 天、20 万条候选日志；超出明确报错，不能静默截断账单。无计费快照的历史模拟只覆盖已验证的 2026 参考政策，后续年份无快照的记录标记未计价；实际计费使用已保存的规则快照，不受 2026 日历限制。
