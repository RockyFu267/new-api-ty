# 页面滚动修复（2026-11-09）

- 需求：自建长页面内容超出视口后，仍能使用滚轮、触摸及滚动条查看底部内容。
- 原因：登录后公共内容区固定高度并隐藏溢出；普通页面未设置独立滚动区域，导致底部被裁切。
- 实现：普通和减少动画模式的路由容器统一允许溢出滚动；我的知识库和 Skill 展示页启用各自内容容器滚动，Skill 内容不再被压缩裁切。已有独立滚动区的标准页面及聊天继续使用自身布局。
- 范围：额度与钱包、部门策略、钱包变动记录、用量分析、DeepSeek 账单 Demo、我的知识库、Skill 展示页等登录后页面。
- 验证：`web/src/components/layout/__tests__/page-scroll.browser.py` 在本地隔离实例中，分别以桌面及窄屏尺寸检查长内容底部可达，并检查聊天外层不产生额外滚动。测试需要 Python websocket-client、Chrome，以及仅本地使用的登录凭据文件；运行参数见脚本说明。
- 不涉及数据库或计费变更；已于 2026-11-10 随功能版本 `8f08bb82` 部署到 47.33，发布记录及备份位于 `/data/app/new-api-ty/update_20261110_113606/`。
