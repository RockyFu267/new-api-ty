TIANYAN 本地编译与启动说明
============================

一、编译前端

打开 PowerShell，执行：

cd D:\code\github\new-api-ty\new-api-ty\web

首次运行或前端依赖发生变化时，先安装依赖：

& "$env:USERPROFILE\.bun\bin\bun.exe" install

编译前端：

& "$env:USERPROFILE\.bun\bin\bun.exe" run build


二、启动后端

cd D:\code\github\new-api-ty\new-api-ty

知识库目录已经配置在项目根目录的 .env 文件中：

KNOWLEDGE_BASE_PATH=../knowledge-base
PRIVATE_KNOWLEDGE_BASE_PATH=../private-knowledge-base

因此可以直接启动服务：

go run .


三、访问地址

http://localhost:3000


四、修改后的重新运行规则

1. 修改前端源码：重新执行 bun run build，然后重启后端。
2. 修改 Go 源码：重启后端。
3. 修改 knowledge-base 中的 Markdown 文件：不需要重新编译，在管理页面重新点击“扫描目录”。
4. 如果前端依赖没有变化，可以跳过 bun install。
5. 如果移动项目或知识库目录，请同步修改项目根目录 .env 中的 KNOWLEDGE_BASE_PATH。
